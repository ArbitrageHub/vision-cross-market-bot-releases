# Vision Fork — releases

Desktop installers for Vision Fork (Polymarket × PS3838). This repo hosts
**built releases only** — no source code.

## Install

See [Installing Vision Fork](./INSTALL.md). Short version:

1. Download the installer for your OS from [Releases](../../releases).
2. Open the app. Server URL is `https://vision-arb.com/arbvision/api`.
3. Enter your license key.

There is no backend to install on your machine or VDS.
